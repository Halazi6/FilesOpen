FilesOpen v1.0 是一款专注于“场景化批量启动”的免费桌面辅助工具。用于集中管理、批量启动、快速定位文件 / 文件夹，支持分组、拖拽、状态标记，备忘，适合项目文档、常用路径统一管理，一键恢复工作环境。

一、核心功能
1、分组管理文件/文件夹
采用树形结构，支持创建任意数量的分组（项目）。
每个分组下可添加多个子项（文件或文件夹）。
备注项目情况及文件用途等。
分组支持优先级状态（★、★★、★★★、||、✔），方便标记任务进度或重要程度。
2、批量启动
勾选任意子项（支持跨分组多选），点击 “启动” 按钮，程序会按照设定的时间间隔依次打开对应的文件或文件夹。
支持为每个子项单独设置打开程序（例如指定用 Notepad++ 打开 .txt 文件），未指定时使用系统默认程序。
3、一键采集
“当前”按钮：自动检测当前任务栏中打开的文件和文件夹（支持按后缀过滤），将识别到的项目连同其关联的程序路径一起添加到新分组中。非常适合快速收集工作文件。
4、灵活的数据管理
拖放添加：直接从资源管理器拖拽文件/文件夹到某个分组下。
图标显示：子项前显示与文件类型关联的系统图标，可设置开关。
单元格编辑：双击（或长按）名称、程序、路径、备注等列可直接修改内容。
搜索定位：顶部搜索框，按关键字实时高亮匹配的行（支持名称、备注、路径）。
排序与移动：支持按钮上移/下移（连续多选）以及鼠标拖拽排序（仅限图标列）。
删除与复制：支持删除选中项。支持复制选中文件或文件夹到剪贴板（可多选）。
5、多语言界面
设置中可切换语言。内置简体中文、English、日本語、한국어、Français、Deutsch、Español、Русский、العربية、Português 共 10 种语言。
6、系统托盘与自动保存
可最小化到托盘。
数据自动保存，并支持每日定时备份到 backups 文件夹。
7、其他
可设置启动时间间隔以及过滤文件扩展名。
无广告、无捆绑：完全免费，纯净绿色。
轻量高效，内存占用低。

二、适用场景
设计师/工程师：某一时间段的工作需打开固定的文件夹、参考文档、设计稿，可将它们分组，一键打开，特别是经常会暂停、切换工作项目的情形。
文案/编辑：需要同时打开多个资料文件和参考网页（通过快捷方式）。
开发人员：打开项目相关的代码文件夹、配置文件、日志文件等。
日常用户：管理常用文件、游戏存档、音乐文件夹等。
